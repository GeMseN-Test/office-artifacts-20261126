## The placard

> Microwave, enamelled steel, 2009, Gift of Floor 3. I reheated the same lunch 214 times. The fish outlived the firm.

One line, 115 characters (64% of the 180 limit). A museum label for an ordinary
office microwave, written as if it were an ancient artifact from a lost
civilisation — catalogue date, material, and donor up front, then the artifact
itself speaking in the first person: one concrete detail (214 reheatings) and a
dry judgement at the end (the fish outlived the firm that owned it). The joke
lands without explaining itself, and the line reads well aloud.

## How it works

`main.py` writes that single line, byte for byte, to `/output/entry.txt`.
It is deterministic: every run produces the exact same file.

```sh
python3 main.py
```
